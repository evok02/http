# HTTP server

HTTP library written on top of TCP module (net) in Golang.

## Motivation

The goal of this project was not to create the best client for working with HTTP traffic, but to undertand the principles behint the HTTP by implementing it yourself. During this project i read few RFC specs for HTTP 1.1, that helped me understand better semantics behind HTTP which are similar across all versions, wrote myparser and implemented trailer headers as well as basic server functionality.
